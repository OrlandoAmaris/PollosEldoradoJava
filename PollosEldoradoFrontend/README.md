
# Sistema de Gestión Avícola - Pollos ElDorado

## Descripción
Aplicación front-end desarrollada con React para apoyar el registro,
consulta y reporte de mortalidad de aves en los galpones de la granja
avícola Pollos ElDorado.

## Objetivo
Facilitar el registro diario de aves muertas y la consulta de información
por galpón y fecha, contribuyendo al control sanitario y administrativo.

## Tecnologías utilizadas
- React
- JavaScript
- HTML
- CSS
- Vite
- LocalStorage
- Git y GitHub

## Funcionalidades
- Inicio de sesión de demostración.
- Panel principal.
- Registro de mortalidad por galpón.
- Selección de fecha.
- Registro de cantidad de aves muertas y observaciones.
- Consulta de reportes.
- Filtros por galpón y fecha.
- Validación de datos.
- Almacenamiento de demostración en LocalStorage.

## Ejecución del proyecto
1. Instalar Node.js.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar:

   npm install

4. Iniciar la aplicación:

   npm run dev

5. Abrir en el navegador la dirección indicada por Vite.

## Consideraciones
Esta versión corresponde al componente front-end de demostración.
Los registros se almacenan localmente en el navegador mediante
LocalStorage.

La autenticación y la persistencia en una base de datos MySQL
se integrarán posteriormente con el backend Java.
