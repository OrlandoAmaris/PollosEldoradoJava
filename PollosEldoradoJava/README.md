# POLLOS ELDORADO - Sistema de Registro de Mortalidad

Proyecto académico desarrollado en Java Web para el registro y
gestión de la mortalidad de aves.

## Tecnologías

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- Maven
- Git

## Módulo desarrollado

Registro de Mortalidad.

## Funcionalidades

- Registrar mortalidad.
- Consultar registros.
- Actualizar registros.
- Eliminar registros.
